# ADR-0002: Политика данных MVP

Статус: принято владельцем 2026-10-01

## Контекст

RFC §8 и §10 требуют согласовать передаваемые данные, маскирование и срок хранения до подключения рабочих сессий.

## Решение

- Все данные aang хранятся только локально, в собственном SQLite, бессрочно до ручного удаления командой CLI.
- Наблюдатель и чат используют уже авторизованный Claude Code или Codex CLI; по умолчанию — вендор наблюдаемого решателя, с переопределением в конфиге.
- Маскирование путей и персональных данных в MVP не выполняется. Перед передачей в LLM вырезаются только очевидные секреты по шаблонам (API-ключи, токены, приватные ключи).
- Инструкции внутри транскриптов передаются наблюдателю как данные; наблюдатель не получает инструментов записи вне хранилища aang.

## Последствия

Минимальная сложность MVP. Перед использованием в корпоративной среде политика пересматривается отдельным решением.
